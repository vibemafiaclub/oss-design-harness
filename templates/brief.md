# Brief

## target — 대상 Figma 문서

> 게이트 G-3에서 사람에게 묻고 채운다. 이게 없으면 제작·A·C단계가 무엇을 대상으로 할지 모른다.

```yaml
target:
  file_url: TODO        # Figma 파일 URL 또는 file key
  page: TODO            # 페이지 이름
  frame: TODO           # 대상 프레임 이름 또는 노드 ID (신규 제작이면 만들 위치)
```

## 보여준 레퍼런스 + 반응 원문

★ **반응은 원문 그대로 적는다. 요약하지 않는다.** 요약하면 역추출의 근거가 사라진다 —
"산만하다"와 "정보가 많아 부담된다"는 서로 다른 기준을 가리킨다.

| # | 레퍼런스 (링크/스크린샷) | 반응 원문 | 좋다/싫다 |
|---|---|---|---|
| 1 | TODO | "TODO — 들은 말 그대로" | (`좋다` 또는 `싫다`로 적는다) |
| 2 | TODO | "TODO" | |

(형식만 참고. 실제 프로젝트에서는 레퍼런스 목록 자체를 새로 만든다.)

## 검증 방식 기록

> 가정이 아니라 **확정된 사실**을 적는다. Figma MCP 폴백으로 갔거나 어떤 단계를 생략했으면

## A단계 기준값

> A단계가 이 블록의 키를 그대로 읽는다. **키 이름은 바꾸지 말고 값만 채운다.**
>
> ★ 값이 비어 있거나 `TODO`로 남아 있으면 A단계는 그 항목을 `SKIP(기준값 없음)`으로 보고하고
>   추측 판정을 하지 않는다. `TODO`를 유효한 값으로 읽지 않는다.
> ★ **정량 임계값은 자유서술 역추출로 만들 수 없다.** 기존 디자인 시스템이 있으면 Figma의
>   변수·스타일을 실측해 채우고, 없으면 사람이 직접 입력한다.

```yaml
tokens:
  color:
    allowed:            # A-1. 허용 색상값/토큰 목록
      - TODO
    exceptions:         # A-1. 팔레트 밖이지만 허용하는 색 (소셜 로그인 브랜드 컬러 등)
      - TODO
  type:
    allowed:            # A-2. 허용 텍스트 스타일 목록
      - TODO
  spacing:
    grid: TODO          # A-3. 그리드 단위 (예: 8)

thresholds:
  component_reuse_min: TODO   # A-4. 컴포넌트 재사용률 하한 (예: 0.7)

naming:
  convention: TODO      # A-5. 레이어 네이밍 컨벤션

variants:
  required_states:      # A-6. 필수 배리언트 상태 (존재 여부만 A단계에서 판정)
    - TODO
```
