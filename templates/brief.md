## A단계 기준값

> A단계가 이 블록의 키를 그대로 읽는다. **키 이름은 바꾸지 말고 값만 채운다.**
>
> ★ 값이 비어 있거나 `TODO`로 남아 있으면 A단계는 그 항목을 `SKIP(기준값 없음)`으로 보고하고
>   추측 판정을 하지 않는다. `TODO`를 유효한 값으로 읽지 않는다.
> ★ **정량 임계값은 자유서술 증류로 만들 수 없다.** 기존 디자인 시스템이 있으면 Figma의
>   변수·스타일을 실측해 채우고(소스=실측), 없으면 사람이 직접 입력한다(소스=사람).

```yaml
tokens:
  color:
    allowed:            # A-1. 허용 색상값/토큰 목록
      - TODO
    exceptions:         # A-1. 팔레트 밖이지만 허용하는 색 (소셜 로그인 브랜드 컬러 등)
      - TODO
  type:
    allowed:            # A-2. 허용 텍스트 스타일 목록
      - TODO
  spacing:
    grid: TODO          # A-3. 그리드 단위 (예: 8)

thresholds:
  component_reuse_min: TODO   # A-4. 컴포넌트 재사용률 하한 (예: 0.7)

naming:
  convention: TODO      # A-5. 레이어 네이밍 컨벤션

variants:
  required_states:      # A-6. 필수 배리언트 상태 (존재 여부만 A단계에서 판정)
    - TODO
```
